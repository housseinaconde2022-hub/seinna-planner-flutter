# Seinna Planner ♥

Une application de planner douce, rose et inspirante pour rêver, s'organiser et briller.

## Version Flutter (mobile)

Cette version est destinée aux téléphones (iOS & Android).

### Installation

1. Assure-toi d'avoir Flutter installé : https://flutter.dev
2. Clone le repo :
   ```bash
   git clone https://github.com/housseinaconde2022-hub/seinna-planner-flutter.git
   cd seinna-planner-flutter
   ```
3. Installe les dépendances :
   ```bash
   flutter pub get
   ```
4. Lance l'application :
   ```bash
   flutter run
   ```

### Fonctionnalités
- Design rose kawaii avec chats noirs, nœuds et cœurs
- Calendrier, Planning, To-Do, Habitudes, Notes, Santé, Self-Care, Objectifs, Budget, Mood
- Interface entièrement en français
- Navigation bottom bar
